## Company Policy Bot Experience

### Overview

Rolan worked on a company policy bot that answers internal company policy questions using AI.

The project used a RAG-based architecture where user questions are matched with relevant policy content before generating an answer.

### Tech Stack

- Python
- LangChain
- Qdrant
- PostgreSQL
- Docker
- Docker Compose
- Telegram bot integration
- Guardrails
- Environment variables
- Database migrations

### System Responsibilities

The system included:

- Telegram bot interface
- User authorization
- RAG chain
- Qdrant retriever
- PostgreSQL database
- Chat history storage
- Guardrails
- Unanswered question logging
- Dockerized deployment

### What the Bot Did

The bot could:

- Receive a user question
- Check whether the user is allowed to use the bot
- Retrieve relevant policy information
- Generate an answer using an LLM
- Include citation-like references
- Store conversation history
- Log low-confidence or blocked questions
